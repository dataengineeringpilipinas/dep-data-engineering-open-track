# Resources

Dataset sources and community links for every phase of the Open Track. Each week's README has its own learning resources; this page is where you look when you need **data** or **people**.

Found a dead link or a source worth adding? Open a PR, this page is meant to be maintained by the community.

## Philippine open data

| Source | What is there | Notes |
| ------ | ------------- | ----- |
| [PSA OpenSTAT](https://openstat.psa.gov.ph) | Official statistics: population, prices, labor, agriculture, trade | Best structured source for PH data; CSV/Excel exports per table |
| [data.gov.ph](https://data.gov.ph) | Government open data portal across agencies | Quality varies by agency; check the resource's last-updated date |
| [PSA main site](https://psa.gov.ph) | Census results, press releases, publications | Some datasets only exist as publication attachments here |
| [PAGASA](https://www.pagasa.dost.gov.ph) | Weather, climate normals, tropical cyclone data | Climate data often requires a written request; start early |
| [BSP Statistics](https://www.bsp.gov.ph/SitePages/Statistics/Statistics.aspx) | Exchange rates, inflation, banking, remittances | Long consistent time series, good for trend projects |
| [Freedom of Information portal](https://www.foi.gov.ph) | Request data no portal publishes | Response takes weeks; a fallback, not a primary plan |
| [HDX Philippines](https://data.humdata.org/group/phl) | Humanitarian data: disasters, population, admin boundaries | Clean geodata (admin boundaries) lives here |
| [World Bank: Philippines](https://data.worldbank.org/country/PH) | Development indicators, decades of history | Easiest API of the bunch if you want to practice ingestion |
