## 📈 Key Preliminary Exploratory Findings

### 1. Contract Cost Distribution (Financial Skewness)
Preliminary statistical summary (`describe()`) indicates severe right-skewness in contract costs across flood control infrastructure:
- **Min Contract Cost:** $\approx ₱0.00$ (indicates placeholders or cancelled bid records requiring filtering).
- **Median Contract Cost:** Significantly lower than the parametric mean, driven by a small number of multi-billion peso mega-projects.
- **Max Contract Cost:** Extreme outliers exceeding standard district-level funding norms, highlighting candidates for statistical $Z$-score anomaly flags.

### 2. Geographic & District Distribution
- Financial allocations are heavily concentrated in disaster-prone river basin corridors (e.g., Central Luzon, Bicol Region, and Cotabato basin).
- High variance in average contract size between rural District Engineering Offices and major urban/regional offices.

### 3. Contractor Concentration Patterns
- Initial `value_counts()` inspection reveals that a minority of construction firms hold disproportionate project volumes across multiple engineering districts.

## 🛠️ Data Anomalies Identified for Transformation (Phase 3 Backlog)

During raw inspection, four primary data cleanliness issues were logged to be resolved during downstream Silver/Gold transformations (Weeks 9–10):

1. **Inconsistent Column Naming:** Source columns (`ProjectId`, `ContractCost`, `DistrictEngineeringOffice`) require conversion to standard `snake_case`.
2. **String Whitespace & Null Variants:** String fields contain leading padding spaces and mixed representations of null values (`"nan"`, `"None"`, `"N/A"`, `""`).
3. **Date Unification:** Raw completion strings require parsing into ISO-8601 timestamps to derive temporal analysis features (`completion_year`, `completion_quarter`).
4. **Coordinate Outliers:** Isolated GPS entries fall outside valid Philippine geographical bounds ($11^\circ \text{N} - 21^\circ \text{N}, 118^\circ \text{E} - 127^\circ \text{E}$).

from pathlib import Path
import pandas as pd

RAW_FILE = Path("data/raw/dpwh_flood_control_projects.csv")

def inspect_raw_dataset():
    if not RAW_FILE.exists():
        print(f"❌ File not found: {RAW_FILE}")
        return

    df = pd.read_csv(RAW_FILE, low_memory=False)
    
    print("==================================================")
    print("      DPWH RAW DATASET PROFILING REPORT           ")
    print("==================================================")
    print(f"Total Rows: {len(df):,}")
    print(f"Total Columns: {len(df.columns)}")
    print("\n--- Column Types and Non-Null Counts ---")
    df.info()
    
    print("\n--- Missing Values Breakdown ---")
    nulls = df.isnull().sum()
    print(nulls[nulls > 0])
    
    print("\n--- Numeric Fields Summary ---")
    print(df.describe().T)
    
    print("\n--- Top 10 Contractors by Project Count ---")
    if "Contractor" in df.columns:
        print(df["Contractor"].value_counts().head(10))

if __name__ == "__main__":
    inspect_raw_dataset()
